# Mon's personal site

A small multi-page personal site: Home, About, Projects, and Contact.

Built with plain HTML, CSS, and JavaScript, and developed step by step with Claude as a way to learn web development.

## Files

- `index.html`, `about.html`, `projects.html`, `contact.html`: the four pages
- `style.css`: the look, shared by every page
- `script.js`: the day counter on the Home page

## Run it locally

Download the files and open `index.html` in a browser. No install needed.

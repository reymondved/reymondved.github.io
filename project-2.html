OJT application tracker

Project 2

About the Project

A tracker for internship (OJT) applications. For each company, I add the role, a status, and a follow-up date, then update the status as the application moves along. It flags follow-ups that are overdue and keeps the list saved in the browser.

Built with HTML, CSS, and JavaScript, with AI assistance. Hosted on GitHub Pages, in its own repository.

Open the app View the code on GitHub

What it does

  • Adds an application with a company, a role, a status, and a follow-up date
  • Lets you change a status from the list as things move forward
  • Flags follow-ups that are overdue, and shows a count for each status
  • Saves the list in the browser, so it is still there next time. Nothing is sent to a server.
  • Fits phone and desktop screens

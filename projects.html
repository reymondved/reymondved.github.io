I'm building my foundations one project at a time, starting with this site.

Personal portfolio website

A multi-page site with Home, About, Projects, and Contact pages. I built it with AI assistance while learning web development, and I can explain how each part works.

Built with HTML, CSS, and JavaScript. Hosted on GitHub Pages.

View the code on GitHub

What it does

  • Four linked pages that share the same menu and design
  • Fits phone and desktop screens
  • Switches between light and dark colors to match the device
  • Uses JavaScript for a day counter that counts the days I worked on the site

What I fixed and learned

  • A list I pasted ran together into one paragraph, because HTML ignores line breaks. A list element (<ul>) fixed it.
  • A menu link appeared outside the menu because it sat outside the <nav> tag. Tags work like boxes, so where something goes decides how it looks.
  • Names have to match exactly. A one-letter difference between an HTML id and the JavaScript that looks for it quietly stops the code from working.

How I built it

  1. First page. Wrote a one-page personal site with HTML for the content and CSS for the style.
  2. Changes by instruction. Practiced describing exactly what I wanted changed, such as colors, wording, and layout.
  3. Reading the code. Learned what HTML, CSS, and JavaScript each control on the page.
  4. Debugging. Practiced finding and fixing bugs: a missing semicolon, a mismatched name, and a misspelled CSS variable.
  5. Multi-page site. Turned one page into four, and added the Projects page and its menu link myself.
  6. Going live. Split the site into separate files, put them in a GitHub repository, and published it with GitHub Pages.
